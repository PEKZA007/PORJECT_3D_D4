# สมุดสะสม

เปิดจากปุ่ม “สมุดสะสม” ในเมนูหลัก เมนูพัก หรือหน้าแสดงผลหลังจบรอบ กดกลับหรือ Esc เพื่อกลับหน้าก่อนหน้า

- สิ่งผิดปกติสะสมเมื่อออกจากชั้น แพ้ หรือกลับเมนูหลักจากการเล่น/พักเกม ไม่จำเป็นต้องเลือกทางถูก
- ใช้ได้ทั้งโหมดง่าย ปกติ และไร้สิ้นสุด พบซ้ำไม่นับเพิ่ม
- รายการที่ยังไม่พบซ่อนชื่อไว้เป็น ??? เพื่อไม่เฉลยระหว่างเล่น
- สิ่งผิดปกติที่ปลดล็อกแล้วแสดงภาพจากฉากเกม รายการที่ยังไม่พบซ่อนทั้งภาพและชื่อ
- สะสม Normal End และ True End แยกกันเมื่อถึงฉากจบ แม้กดข้ามคัทซีนก็เก็บไว้
- กด “ดูฉากจบอีกครั้ง” ใต้ฉากจบที่ปลดล็อกเพื่อชมคัทซีนจากสมุด กด E / Esc เพื่อข้าม ดูจบแล้วกลับสมุด หากเปิดจากเมนูพักจะรักษาห้อง ตำแหน่งผู้เล่นและของที่เก็บไว้
- รอบทดสอบที่บังคับเหตุการณ์หรือเข้า Event Lab ไม่เพิ่มสมุดสะสม
- แสดงความคืบหน้าเฉพาะเหตุการณ์ที่เปิดใช้งาน ปัจจุบัน 26 รายการ เหตุการณ์ 15 ที่ปิดไว้ไม่ถูกนับในเป้าหมาย

ข้อมูลอยู่ใน user://progress.cfg ร่วมกับการปลดล็อกไร้สิ้นสุดและสถิติ เริ่มรอบใหม่หรือแพ้ไม่ล้างข้อมูลสะสม การอัปเดตจากไฟล์เซฟเดิมจะรักษาการปลดล็อกและสถิติไว้ แต่เหตุการณ์และฉากจบก่อนมีระบบนี้ไม่ได้ถูกบันทึกย้อนหลัง
