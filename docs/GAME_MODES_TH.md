# โหมดเกม

เลือกโหมดจากเมนูหลักก่อนเริ่มรอบ

1. ง่าย: กฎเดิมทั้งหมด เพิ่มเสียงคิดในใจเป็นข้อความทุกชั้น เตือนให้มองและฟังในภาพรวม ข้อความไม่อิงเหตุการณ์ที่สุ่ม ไม่เฉลยสิ่งผิดปกติหรือทิศทางออก
2. ปกติ: ผ่านห้อง 7 เพื่อดู Normal End หรือ True End ตามการเก็บเครื่องราง จำกัด stamina ให้วิ่งต่อเนื่องได้ 6 วินาที พลังฟื้นหลังหยุดวิ่ง 1.5 วินาที ที่ 0.8 หน่วยต่อวินาที เมื่อหมดต้องฟื้นถึง 25% ก่อนวิ่งต่อ เปลี่ยนห้องคืนพลังเต็ม พักเกมหยุดการใช้และฟื้นพลัง
3. ไร้สิ้นสุด: ปลดล็อกหลังจบโหมดง่ายหรือปกติครั้งแรก รวมทั้ง Normal End และ True End การปลดล็อกบันทึกข้ามการเปิดเกม

ไร้สิ้นสุดเริ่มที่ห้อง 1 ปลอดภัย จากนั้นสุ่มเหตุการณ์ต่อไปเกินห้อง 7 ไม่มีคัทซีนจบและเครื่องราง กฎกระดิ่งวนตามห้อง 2, 3, 5 ของทุกชุด 7 ชั้น ผิดครั้งเดียวจบรอบ เล่นใหม่หรือกลับเมนูได้

หน้าจอแสดงชั้นปัจจุบัน จำนวนชั้นที่ผ่าน และสถิติสูงสุด จบรอบแสดงเวลาและจำนวนชนิดความผิดปกติที่พบ พร้อมปุ่มคัดลอกข้อความสถิติเพื่อนำไปแชร์

สถิติเป็นสถิติส่วนตัวในเครื่อง ไม่มีอันดับออนไลน์ เก็บจำนวนชั้นสูงสุด พร้อมเวลาและจำนวนความผิดปกติของรอบนั้น ถ้าผ่านเท่ากันใช้เวลาสั้นกว่าเป็นสถิติใหม่ บันทึกหลังผ่านแต่ละชั้นเพื่อรักษาสถิติหากปิดเกม

ข้อมูลเก็บใน user://progress.cfg แยกจากการตั้งค่าเสียง รอบที่บังคับเหตุการณ์หรือเข้า Event Lab ไม่ปลดล็อกและไม่นับสถิติ
