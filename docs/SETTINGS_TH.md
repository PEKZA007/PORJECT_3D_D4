# การตั้งค่า

เปิดจากเมนูหลัก เมนูพัก หรือหน้าจบเกม

- ภาษา / Language: เลือกไทยหรือ English เปลี่ยนทันทีและจำค่าหลังเปิดเกมใหม่ ครอบคลุมเมนู กระดาษกฎ คำใบ้ ชื่อเหตุการณ์ สมุดสะสม สถิติ และคำบรรยายฉากจบ ชื่อบุคคลในเครดิตคงตามต้นฉบับ

- ขนาดหน้าต่าง: 960×600, 1152×720, 1280×800 (ค่าเริ่มต้น), 1440×900, 1600×900, 1920×1080 หากใหญ่กว่าพื้นที่จอจะปรับให้พอดีและวางกลางจอ
- เต็มหน้าจอ: ใช้ขนาดของจอ เมื่อเปิดจะปิดตัวเลือกขนาดหน้าต่างชั่วคราว ปิดแล้วคืนขนาดหน้าต่างที่เลือกไว้
- เสียง: 0–100% ควบคุมเสียงทั้งหมด ค่าเริ่มต้น 75% ตั้ง 0% จะปิดเสียง
- เสียงเพลงพื้นหลัง: 0–100% แยกจากเสียงรวม ค่าเริ่มต้น 75% ตั้ง 0% ปิดเฉพาะเพลง The Surreal Truth เพลงวนซ้ำและเล่นต่อในเมนูพัก/ตั้งค่าเพื่อฟังระดับเสียงขณะปรับ เสียงรวมยังควบคุมเพลงด้วย
- ความสว่างหน้าจอ: 60–140% ค่าเริ่มต้น 100% ปรับภาพเกม เมนู และคัทซีนทันที ไม่เปลี่ยนแสงหรือการทำงานของเหตุการณ์
- ความไวเมาส์: 0.5–3 เท่า ค่าเริ่มต้น 1 เท่า

บันทึกอัตโนมัติใน user://settings.cfg และคืนค่าหลังเปิดเกมใหม่ ปุ่ม “คืนค่าเริ่มต้น” คืนค่าทั้งหมด หน้าตั้งค่าเลื่อนได้เพื่อรองรับจอขนาดเล็ก

หากเล่นฝังใน Godot Editor ตัว Editor จะควบคุมขนาดแทนเกม ปิด Game → เมนูด้านขวา → Embed Game on Next Play แล้วหยุด/เริ่มเกมใหม่ หรือดับเบิลคลิก Launch JUBUTSU.cmd ในโฟลเดอร์โปรเจกต์เพื่อเล่นในหน้าต่างแยก ขณะฝังใน Editor หน้าตั้งค่าจะแสดงคำแนะนำและปิดตัวเลือกขนาดที่ใช้ไม่ได้

Launch JUBUTSU.cmd เปิดเกมแบบเต็มจอจริงเสมอ แม้เคยบันทึกโหมดหน้าต่างไว้ ภาพขยายตามสัดส่วนจอโดยไม่มีขอบดำ หากต้องการหน้าต่างให้ปิด “เต็มหน้าจอ” ในการตั้งค่าหลังเข้าเกม
