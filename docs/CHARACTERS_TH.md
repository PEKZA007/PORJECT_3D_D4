# โมเดลและแอนิเมชันตัวละคร

## ไฟล์ที่ใช้

- assets/models/npc.glb: โมเดลผู้ชายและคลิป Walk จากไฟล์ที่ส่งมา
- assets/models/player.glb: โมเดลผู้หญิงต้นฉบับ ไม่มี skin, skeleton หรือ animation ในไฟล์ที่ได้รับ
- assets/models/player_animated.tscn: ฉากผู้เล่นที่เพิ่มโครงกระดูกและท่า Idle, Walk, Run เปิดแก้ใน Godot ได้โดยตรง
- tools/build_player_rig.gd: เครื่องมือสร้างโครงกระดูกและคลิปพื้นฐานใหม่ การรันจะเขียนทับ player_animated.tscn ให้สำรองก่อนแก้ด้วยมือ

ต้นฉบับทั้งสอง GLB ถูกคัดลอกมาโดยไม่แก้ข้อมูล

## การแสดงในเกม

NPC แทนคนเดิน คนที่หน้าต่าง คนแง้มประตู และผู้ไล่ตาม ท่า Walk วนซ้ำตามการเดิน ผู้ไล่ตามใช้คลิปเดียวกันที่เร็วขึ้น 1.75 เท่า ท่ายืนนิ่งของ NPC ใช้เฟรมตั้งต้นของ Walk

ผู้เล่นใช้มุมมองบุคคลที่หนึ่ง โมเดลเต็มตัวแสดงในกระจกบน render layer 8 เพื่อไม่ให้ใบหน้าหรือผมบังกล้องของตัวเอง เดิน/วิ่ง/หยุดจะเปลี่ยนคลิปพร้อมผสมท่า แอนิเมชันหยุดเมื่อพักเกม

เหตุการณ์กระจกใช้ตัวผีแยกบน layer 4 แล้วซ่อนตัวผู้เล่นจากกล้องกระจก เอฟเฟกต์ไร้หน้าใช้ชิ้นปิดใบหน้าติดกับกระดูกศีรษะ รุ่นผีและผู้ไล่ตามใช้การปรับสีของโมเดล NPC

## แก้ต่อ

- เปลี่ยนโมเดล NPC ใน Inspector ของ Props/Walker และ actor อื่น ช่อง Normal Model และ variant ต่าง ๆ
- Walk Animation เป็นชื่อคลิปใน GLB ปัจจุบันคือ Walk; Model Rotation Degrees.Y=180 เพื่อให้หน้าตรงกับทิศเดิน
- เปิด player_animated.tscn แล้วเลือก AnimationPlayer เพื่อแก้ Idle/Walk/Run การเคลื่อนที่จริงยังควบคุมด้วย scripts/player.gd
- การสร้างน้ำหนักกระดูกของผู้เล่นเป็นแบบพื้นฐานตามตำแหน่งจุด เหมาะกับการเดินและวิ่งเบื้องต้น ยังควรเก็บน้ำหนักมือ กระโปรง และท่าทางในโปรแกรมทำโมเดลหากต้องการงานแอนิเมชันละเอียด
- ไฟล์ NPC มีเฉพาะ Walk จึงยังไม่มีคลิปเฉพาะสำหรับยื่นของหรือชก การใส่ท่าเหล่านั้นเพิ่มเติมควรใช้ rig เดียวกัน

## ตรวจงาน

เครื่องมือ tools/test_characters.gd ตรวจการโหลดคลิป การหยุดแอนิเมชันเมื่อเกมหยุด และบันทึกภาพตัวละครกับกระจก ภาพอยู่ใน docs/npc-animated.png, player-animated.png, player-mirror.png และ npc-faceless.png

## กล้องเห็นเท้า

Player ปรับ Eye Height=1.49 และ Eye Forward Offset=0.40 ใน Inspector ได้ กล้องลดระยะด้านหน้าเมื่อชนผนัง ตัวเต็ม layer 8 แสดงในกระจก ตัวบุคคลที่หนึ่ง layer 16 ตัดศีรษะออกและใช้กระดูกชุดเดียวกัน ทำให้เห็นมือ ลำตัว และรองเท้าเมื่อก้ม

assets/models/first_person_*.res สร้างด้วย tools/build_first_person.gd หากแก้รูปทรงหรือกระดูก player_animated.tscn ให้สร้างไฟล์เหล่านี้ใหม่ด้วย
