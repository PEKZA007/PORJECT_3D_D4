# โมเดลและงานภาพที่ต้องการเพิ่ม

อัปเดต 6 ตุลาคม 2026: ได้รับและใส่กระดิ่ง ถังดับเพลิง ถังขยะ ลำโพง เครื่องราง หน้ากาก โต๊ะเก้าอี้จากชุดห้องเรียน เพลง และเสียงระฆังแล้ว ดู `ASSETS_UPDATE_TH.md` รายการด้านล่างเป็นรายการเดิมก่อนรับไฟล์ชุดนี้

ตัวเกมปัจจุบันเล่นได้ด้วย placeholder ทั้งหมด รายการนี้ใช้เปลี่ยนให้เป็นงานภาพจริง ไม่ได้เป็นเงื่อนไขก่อนเปิดเกม

## ส่งก่อน: ตัวละคร

1. **คนเดินในโรงเรียน 1 ตัว** สูงประมาณ 1.65–1.8 เมตร มีใบหน้าที่มองตาได้ พร้อมท่ายืนและเดิน
2. **เวอร์ชันไร้หน้า** ใช้ rig เดียวกับตัวปกติได้ สำหรับเหตุการณ์ 8
3. **ท่ายื่นของและพร็อพที่ยื่น** สำหรับเหตุการณ์ 5 (กล่องเล็ก เครื่องราง หรือวัตถุที่คุณเลือก)
4. **ผีสำหรับภาพสะท้อน** ใช้สัดส่วนเดียวกับคนเดิน แต่ใบหน้า/ผิว/ชุดแตกต่างชัดเจน สำหรับเหตุการณ์ 9
5. **ผู้ไล่ตามที่กลืนกับผนัง** พร้อมท่าวิ่งและต่อย สำหรับเหตุการณ์ 21; ปัจจุบันใช้เข้าประชิดแล้วตัดภาพ
6. **มือและแขน** แยกชิ้นพร้อมท่างอนิ้ว/โผล่จากถัง สำหรับเหตุการณ์ 25

คนแง้มประตูและคนนอกหน้าต่างใช้โมเดลคนปกติร่วมกันได้ คนตัวเล็กใช้ย่อสเกล ไม่ต้องทำโมเดลเพิ่ม

## ฉากและวัตถุ

- **ห้องน้ำชายขนาดเล็กหรือซุ้มประตูห้องน้ำ** มีบานประตูแยกและ pivot ที่บานพับ สำหรับเหตุการณ์ 10
- **อ่างล้างมือพร้อมก๊อก** แยกหัวก๊อกและจุดปล่อยน้ำ สำหรับเหตุการณ์ 26
- **กระดิ่งติดผนัง**, **ถังดับเพลิง**, **ถังขยะเปิดฝา**, **ลำโพงประกาศ** ใช้แทนรูปทรงชั่วคราว
- **ชุดโต๊ะเก้าอี้และห้องเรียน** หากต้องการห้องที่มีรายละเอียดมากกว่าฉากเสริมปัจจุบัน

ประตูเลื่อน กรอบกระจก และป้ายทำด้วยรูปทรงใน Godot ได้อยู่แล้ว ไม่จำเป็นต้องส่งถ้าใช้รูปแบบเรียบง่ายต่อ
ใช้บันได ดาดฟ้า และชั้นใต้ดินของโมเดลเดิมเป็นพื้นที่เดินแล้ว ทางผ่านรอบอยู่สุดทางเดิน ไม่ต้องส่งโมเดลเพิ่มเพื่อขยายแมพรอบนี้

## ภาพและเสียงที่ไม่ต้องทำเป็นโมเดล

- โปสเตอร์โรงเรียนปกติ 3–5 ภาพ และแบบผิดปกติอย่างน้อย 2 ภาพ (ใบหน้าหลอน / ภาพหลอนอื่น)
- คราบเลือด เลือดไหล และผิวหน้าหลอน: PNG โปร่งใสหรือชุด PBR
- เสียงฝีเท้า กระดิ่ง เคาะประตู น้ำไหล ประตูเลื่อน และบรรยากาศโรงเรียน

## รูปแบบไฟล์ที่สะดวกต่อการใส่เกม

- แนะนำ **.glb** พร้อม texture ฝังในไฟล์
- หน่วยเมตร; เท้าอยู่ Y=0; แกน Y ขึ้น; ด้านหน้าตัวละครไป -Z
- ประตู บานพับ ก๊อก มือ และของที่ยื่นแยกชิ้น/กระดูกให้ขยับได้
- ถ้ามี animation แจ้งชื่อคลิป เช่น idle / walk / run / offer / punch
- ส่งรายละเอียดสิทธิ์ใช้งานหรือชื่อผู้สร้างมากับไฟล์ เพื่อเพิ่มเครดิตได้ถูกต้อง

เริ่มจากคนเดินและผีสะท้อนก่อนจะเห็นความเปลี่ยนแปลงของบรรยากาศมากที่สุด
