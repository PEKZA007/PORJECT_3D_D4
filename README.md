# JUBUTSU — The Seventh Room

เกมต้นแบบเล่นได้ใน Godot: ทางเดินโรงเรียนวนซ้ำ สังเกตความผิดปกติและหาทางออกที่ห้อง 7
สร้างตาม `docs/original_brief.txt` ใช้โมเดลโรงเรียนที่ผู้ใช้ให้มา พร้อมเหตุการณ์ต้นแบบครบ 27 รายการ

## เริ่มเล่น

1. เปิด `project.godot` ด้วย Godot 4.7.2 (เวอร์ชันที่ใช้ทดสอบ)
2. รอ import ครั้งแรก แล้วกด **F5**
3. กด “เข้าสู่ทางเดิน” ใช้เมาส์มองและ WASD เดิน

ไม่ต้องติดตั้งปลั๊กอิน ไม่ต้องดาวน์โหลดโมเดลเพิ่มเพื่อทดลองเล่น
ฉากหลักคือ `scenes/main.tscn` ส่วนฉากที่ใช้จัดวัตถุคือ `scenes/school_level.tscn`

## การควบคุม

เลือกเล่นได้ 3 โหมดจากเมนูหลัก: **ง่าย** มีข้อความคิดในใจช่วยชวนสังเกตทุกชั้น, **ปกติ** ใช้กฎเดิม, และ **ไร้สิ้นสุด** ปลดล็อกเมื่อจบเกมครั้งแรก เดินต่อได้ไม่จำกัดและจบรอบเมื่อพลาด พร้อมสถิติส่วนตัวและปุ่มคัดลอกเพื่อแชร์ ดูรายละเอียดใน `docs/GAME_MODES_TH.md`

เปิด **สมุดสะสม** จากเมนูหลัก เมนูพัก หรือหน้าจบ เพื่อดูสิ่งผิดปกติที่เคยพบและ Normal End / True End ที่ปลดล็อกแล้ว บันทึกข้ามการเปิดเกม รายการที่ยังไม่พบซ่อนชื่อกันสปอยล์ ดู `docs/COLLECTION_TH.md`

- WASD: เดิน / เมาส์: มอง
- Shift ค้าง: วิ่ง
- E: อ่านกระดาษ สั่นกระดิ่ง หรือโต้ตอบกับสิ่งที่มองอยู่
- F: เปิด–ปิดไฟฉาย
- Esc: พักหรือกลับเข้าเกม; อ่านกฎละเอียดได้จากกระดาษในฉากเท่านั้น
- F3: เปิด Event Lab เฉพาะเมื่อเปิด Debug Enabled ใน Inspector (ปิดไว้เป็นค่าเริ่มต้น)

## กฎที่ใช้ในต้นแบบ

- ห้อง 1 เป็นทางเดินปกติเพื่อให้จำฉากได้ กระดาษอยู่ที่ห้องนี้ตามปกติ
- พบความผิดปกติให้เดินกลับจนพ้นปลายทางด้านหลัง; ไม่พบให้เดินผ่านปลายทางด้านหน้า
- ทำถูกจะไปหมายเลขถัดไป ทำผิดกลับห้อง 1
- ห้อง 2, 3, 5 ต้องกดกระดิ่ง **หนึ่งครั้งก่อนออกจากรอบ** ไม่ว่าจะเดินต่อหรือย้อนกลับ กดซ้ำก็ผิด
- ห้องอื่นไม่บังคับกระดิ่ง และไม่ลงโทษการกดกระดิ่ง
- เหตุการณ์ 27: ป้ายห้ามวิ่ง — เดินไปข้างหน้าต่อไป ปุ่มวิ่งถูกปิด หยุดจนชายข้างหลังตามทันหรือเดินย้อนกลับจะเริ่มใหม่
- เครื่องรางสุ่มหนึ่งในด่าน 1–7 เก็บด้วย E และติดตัวจนจบจะได้ True Ending; ไม่เก็บจะได้ Normal Ending เมื่อแพ้หรือเริ่มเกมใหม่จะล้างเครื่องรางและสุ่มด่านใหม่ ของจาก NPC ยังเป็นกับดัก
- ห้อง 7 ไม่มีความผิดปกติ เดินไปทางออกด้านหน้าเพื่อจบเกม
- กดตามป้ายทางออกก่อนห้อง 7, รับของจากคนแปลกหน้า หรือสบตาคนเดินเกิน 1.8 วินาที จะเริ่มใหม่
- ความผิดปกติฝีเท้า/ผู้ไล่ตามต้องวิ่งหนีจนหายไป (ค่าเริ่มต้น 3 วินาที) แล้วจึงเลือกทางตามกฎ
- โหมดปกติมี stamina: วิ่งได้ 6 วินาที ฟื้นหลังหยุดวิ่ง 1.5 วินาที เมื่อหมดต้องฟื้นถึง 25% ก่อนวิ่งต่อ เปลี่ยนห้องจะคืนพลังเต็ม โหมดง่ายและไร้สิ้นสุดวิ่งได้ไม่จำกัด

ไม่มีตัวนับกระดิ่ง ข้อความเตือนระหว่างเหตุการณ์ หรือคำเฉลยสาเหตุที่เริ่มใหม่ ให้จำกฎจากกระดาษและดูเลขห้องจากป้ายจริงในฉาก เมนูก่อนเริ่มบอกเฉพาะเดินต่อ/ย้อนกลับและเป้าหมายห้อง 7

กฎกระดิ่งปรับเป็นห้อง 2, 3, 5 เพราะห้อง 7 เป็นทางออก อ่านระบบเครื่องรางและเหตุการณ์ใหม่ใน `docs/SEVEN_ENDINGS_TH.md`

## แก้เกมตรงไหน

- **ความยาก / โอกาสเกิด / ความเร็ว / กระดิ่ง / ระยะสบตา:** เปิด `data/game_config.tres` แล้วแก้ใน Inspector
- **เปิดปิดเหตุการณ์ / น้ำหนักสุ่ม / ห้องเริ่มเกิด / ชื่อ:** `data/anomalies.json`
- **ย้ายวัตถุ เปลี่ยนแสงหรือวัสดุ:** เปิด `scenes/school_level.tscn` แล้วแก้ใต้ `Props` หรือ `Lights`
- **เปลี่ยนโมเดลคนและผี:** เลือก `Props/Walker` หรือ `Props/Pursuer` แล้วลาก GLB ลงช่องโมเดลใน Inspector
- **เมนู ภาษา สีและขนาดตัวหนังสือ:** `scripts/hud.gd`
- **กฎผ่าน/ไม่ผ่าน:** `scripts/run_rules.gd`
- **เพิ่มพฤติกรรมความผิดปกติ:** `scripts/anomaly_director.gd`

อ่านขั้นตอนละเอียดใน `docs/EDITING_TH.md` และรายการโมเดลที่ควรส่งเพิ่มใน `docs/ASSETS_NEEDED_TH.md`

## สถานะงาน

มีการเล่นตั้งแต่เมนูจนจบ ระบบวนรอบ สุ่มแบบมีน้ำหนัก ไม่สุ่มเหตุการณ์เดิมซ้ำจนกว่าจะใช้รายการที่มีสิทธิ์หมด กระดิ่ง สบตา ไล่ตาม กระจกสะท้อนจริง ไฟฉาย เสียงสามมิติ และโหมดเลือกเหตุการณ์

โมเดลคน ผู้เล่น กระดิ่ง ลำโพง ถังขยะ ถังดับเพลิง เครื่องราง หน้ากาก และโต๊ะเก้าอี้ห้องเรียนใส่แล้ว ส่วนมือ โปสเตอร์อื่น และห้องน้ำยังเป็น **placeholder** เพลงพื้นหลังและเสียงกระดิ่งใช้ไฟล์ที่ส่งมา เอฟเฟกต์อื่นยังเป็นเสียงสังเคราะห์ชั่วคราว ดูรายละเอียดใน `docs/ASSETS_UPDATE_TH.md`
แอนิเมชันยื่นของ/โจมตียังเป็นท่าทางต้นแบบ ผู้ไล่ตามทำให้แพ้เมื่อเข้าถึงตัว ยังไม่มีท่าต่อยจากโมเดล rig
ใช้ทางเดินยาวของ GLB เป็นพื้นที่เล่นหลัก ทางผ่านรอบอยู่สุดทางเดิน ส่วนทางย้อนกลับอยู่ปลายทางเดินด้านจุดเกิด ไม่มีการวาร์ประหว่างพื้นที่เหล่านี้
ปิดทางไปบันได ชั้นใต้ดิน และดาดฟ้าแล้ว กด E ที่มือจับประตูเลื่อนเพื่อเข้าห้องเรียนได้ ห้องน้ำยังเป็นฉากประกอบ ไม่ใช่ห้องที่เข้าไปสำรวจ
กระจายจุดสังเกตตามทางเดิน ชานพัก และดาดฟ้า ดูรายละเอียดการจัดพื้นที่และการแก้ไขใน `docs/MAP_TH.md`

บันทึกการปลดล็อกโหมดไร้สิ้นสุดและสถิติส่วนตัวข้ามการเปิดเกมแล้ว ยังไม่มีระบบเซฟระหว่างรอบ ไม่มีจอยแพด และยังไม่ทำแพ็กเกจเผยแพร่หรือไฟล์ .exe
ฟอนต์ไทยใช้ SystemFont บนเครื่อง (Leelawadee UI / Noto Sans Thai / Tahoma); หากเผยแพร่หลายระบบ ควรใส่ฟอนต์ไทยที่มีสิทธิ์แจกจ่าย
